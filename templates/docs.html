API Documentation

Overview

The Reel Ranker API provides intelligent ranking of reel data based on conversation relevance. It uses OpenAI's embedding models and GPT-4o to understand context and determine the most relevant content.

Endpoints

POST /api/rank_reels

Description: Ranks reel data based on relevance to the conversation.

Request Body
{
  "query": "string",                     // Required: Current user query
  "conversation_history": [              // Optional: Previous conversation messages
    {
      "role": "user" | "assistant",      // Role of the message sender
      "content": "string"                // Content of the message
    }
  ],
  "reels": [                             // Required: Array of reels to rank
    {
      "id": "string",                    // Unique identifier for the reel
      "title": "string",                 // Reel title
      "description": "string",           // Reel description
      "tags": ["string"],                // Array of tags
      // Other optional fields can be included and will be considered
    }
  ]
}
Response
{
  "success": true,                       // Boolean indicating if request was successful
  "ranked_reels": [                      // Array of reels ordered by relevance
    {
      "id": "string",                    // Original reel ID
      "title": "string",                 // Original reel title
      "description": "string",           // Original reel description
      "relevance_score": 0.92,           // Score between 0-1 indicating relevance
      "explanation": "string",           // Optional explanation of the ranking (for top reels)
      // All original fields are preserved
    }
  ]
}
Error Response
{
  "success": false,
  "error": "string"                      // Description of the error
}

GET /api/health

Description: Checks the health status of the API and its connection to OpenAI.

Response
{
  "status": "healthy" | "degraded",
  "openai_connection": "connected" | "disconnected",
  "error": "string"                      // Only present if status is degraded
}

Ranking Methodology

The API uses a two-step process to rank reels:

  1. Vector Embedding Similarity: All reels are initially ranked based on cosine similarity between the conversation context embedding and the reel content embedding.
  2. LLM-Enhanced Ranking: For the top reels, an additional analysis is performed using GPT-4o to provide a more nuanced understanding of relevance, including explanations for top rankings.

Best Practices

  • Include as much relevant information in your reels as possible (title, description, tags, etc.)
  • Provide conversation history for better context understanding
  • Keep queries focused and specific for more accurate rankings
  • Limit the number of reels to rank (preferably under 50) for optimal performance
