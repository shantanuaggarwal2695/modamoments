AI-Powered Reel Ranking

This API leverages OpenAI to rank reels based on their relevance to a conversation. Simply provide a user query, conversation history, and reel data to receive ranked results ordered by relevance.

Features:

  • Semantic understanding of conversation context
  • Vector embedding-based matching
  • Detailed relevance scoring
  • OpenAI-powered advanced ranking
  • Fast and efficient processing

Try it out

Use the example request below to test the API:

{
  "query": "Show me videos about cooking pasta",
  "conversation_history": [
    {"role": "user", "content": "I'm looking for food tutorials"},
    {"role": "assistant", "content": "What kind of food are you interested in?"}
  ],
  "reels": [
    {
      "id": "reel1",
      "title": "Ultimate Pasta Carbonara",
      "description": "Learn how to make the perfect pasta carbonara",
      "tags": ["cooking", "pasta", "italian"]
    },
    {
      "id": "reel2",
      "title": "Summer Grilling Tips",
      "description": "Best practices for outdoor grilling",
      "tags": ["cooking", "grilling", "summer"]
    }
  ]
}

Send a POST request to: /api/rank_reels
